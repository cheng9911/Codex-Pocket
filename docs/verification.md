## 主机密码与设备授权

新增 5 项测试覆盖：随机盐和 scrypt 哈希、配置权限与格式拒绝、旧配对授权迁移、密码变更后的全设备失效、缺失配置不降级、密码会话重建保留、主机间 Cookie 隔离、持久限流、并发限制、HTTP 来源与参数检查、30 天记忆与 12 小时会话模式、退出与撤销后 HTTP/WS 失效，以及本地 stdin 设置命令不输出密码。交互终端还验证了两次输入不回显。

浏览器在两台独立的隔离测试服务上分别使用不同密码登录，切回第一台主机时直接恢复授权；刷新后也保持登录。验证错误密码提示、密码输入清空、设备名称和到期时间、撤销当前设备后返回登录页。手机 390px 页面无横向溢出，截图只含测试主机数据。真实主机密码由使用者在本机终端设置，测试密码不会写入正常配置。

## 本机已有聊天与跨进程控制

新增 5 项自动化测试覆盖：列表分页与重复发现、保留自定义名称、只读打开不恢复执行、历史分页顺序与重复 item ID、原 ID 继续、消息合并去重、恢复后的审批和停止、释放、占用锁与工作目录边界、重启回到历史、接口授权与来源检查。

`npm run verify:local` 使用真实 Codex 和独立临时聊天验证通过：发现聊天、读取历史、原端退出后在同一个 ID 继续得到 `POCKET_CONTINUED_OK`、中断确认、释放后第三个进程成功恢复。测试成功后归档这条临时聊天，删除临时项目及 Pocket 数据库。测试读取了本机列表元数据，但没有修改用户已有聊天。

跨进程验证结果：持有写入锁时恢复返回 `already has an active writer`，未拥有会话的进程追加/停止均返回 `thread not found`。没有建立原进程审批订阅，因此不能转发原端审批。测试使用与桌面同版本的 app-server 独立进程复现进程边界，未操作用户桌面端正在运行的真实任务，不把此实验表述为桌面 UI 接管验收。

读取外部历史时观察到：原进程仍执行，而读取端元数据为 `notLoaded`、最近轮次可能为 `interrupted`。页面因此统一显示“历史查看”，不会据此伪造“已结束”。取消订阅有默认卸载宽限期；Pocket 对自己的子进程设置 0 秒并确认卸载，真实验证其他进程随后能够继续。

浏览器增量验收使用显式测试历史：自动发现、历史翻页、继续后审批/停止、释放、占用错误、中英文切换均通过。390、768、1440 CSS 像素下无横向溢出；手机保持列表/详情切换，桌面保持双栏。新增控件沿用现有 Taste 风格与阿里巴巴普惠体，源码检查 0 FAIL / 0 WARN，浏览器控制台无错误；未启动第二套浏览器驱动，截图与尺寸检查均通过 CUA 完成。
