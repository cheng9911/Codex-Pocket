# 首版验证记录

日期：2026-11-18（Asia/Shanghai）。主机：Ubuntu 22.04 x86_64，Node.js 22.23.3，Codex CLI 0.167.0-alpha.3.2。

## 自动检查

- `npm run check`：TypeScript 检查通过。
- `npm test`：10 项测试通过；使用独立 JSONL 进程，经真实 T3 通信层验证，不依赖模型或账号。
- `npm run verify:vendor`：10 个上游源码文件 SHA-256 与固定提交一致。
- `npm run build`：生产构建通过。
- 界面技能源码检查：0 FAIL、0 WARN。

测试覆盖一次性配对、来源校验、HTTP/WS 鉴权、撤销后断开连接、客户端离线不停止任务、路径与符号链接边界、审批竞争、相同目录排队、不同目录执行、指定聊天中断、重复消息去重、并发队列唤醒、问题回答、进程退出、重启标记、主机会话隔离和历史分页。

## 真实 Codex

- `verify:transport`：通过，初始化并读取模型目录。
- `verify:live`：通过，临时项目中得到真实模型回复；验证服务重启后的空聊天重建，以及已有原生聊天恢复并保留上一轮内容。
- `verify:controls`：通过，收到一项原生命令审批，允许后成功写入临时标记文件；另一轮执行通过 `turn/interrupt` 确认中断。

真实模型测试没有读取用户项目文件，所有文件写入均在脚本创建的临时目录中。临时项目与 Pocket 测试数据库在完成后清理；Codex 自身可能保留测试聊天历史。

## 浏览器

使用隔离测试主机完成配对、新建聊天、消息、批准/拒绝、回答问题、停止、刷新恢复，以及在两个独立服务之间切换并保留各自授权。截图中的 `approval`、`printf test` 等属于显式测试数据，正常服务不注入这些内容。

已检查 375、390、768、1440 CSS 像素宽度；已保存移动、平板与桌面截图到忽略的 `artifacts/`。页面无横向溢出，Inter 本地字体已加载，移动聊天页可见文字不小于 11px。桌面采用双栏，手机采用列表/详情切换。

截图与 UI 检查经 CUA 浏览器完成，没有接入第二套 CDP 驱动。隔离测试主机不包含真实 Codex 账号或文件执行能力。
