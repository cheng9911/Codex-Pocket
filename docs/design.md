# 页面设计记录

面向用户的核心问题：哪个聊天正在执行，哪个聊天需要我做决定？

参考用户指定的 T3 聊天界面。采用 design-taste-frontend 的 true-black-flat 方向，seed 1738442261；因聊天列表与详情需要持续切换，将抽取到的无侧栏 shell 调整为桌面双栏、手机单栏。保留中性暗色、平面明度层次、反白操作按钮和仅用于状态的颜色。

产品特征是每个聊天旁的执行状态，以及紧邻消息流的审批/回答卡片。主机名称始终在列表顶部，详情可直接切换主机。Inter 本地字体用于界面，IBM Plex Mono 本地字体用于代码，不依赖手机访问外部字体服务。中文使用系统字体。

ui-ux-pro-max 的设计系统检索两次均给出不适合本产品的文档落地页结构，未采用或保存这些结构。可访问性、触摸目标、移动端布局按其通用规范及本产品需求实现。弹层支持 Escape、Tab 焦点约束和关闭后焦点恢复，控件有可访问名称。

正常服务从真实状态渲染，不注入演示聊天。`scripts/preview-test.ts` 中只有显式浏览器验收用的进程模拟与临时聊天，页面截图若来自该预览必须标注为测试数据。

界面源码规则检查无 FAIL/WARN。响应式截图与可见 DOM 测量通过受支持的 CUA 浏览器完成；未另行启动技能自带的 CDP 控制器，避免同时使用两套浏览器控制通道。
